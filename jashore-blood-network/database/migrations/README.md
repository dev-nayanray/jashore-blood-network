# Database migrations will live here in Phase 3.

This directory is reserved for Prisma migration SQL files. Phase 2 leaves it
empty. The first migration (initial schema) will be created in Phase 3 when
the Prisma schema is written.

Do not edit migration files manually after they have been applied to any
shared database (dev, staging, or production). To reverse a migration,
write a new migration that reverses the previous one.
